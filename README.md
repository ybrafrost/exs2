# Excelsior Perú - Cristal Templado Arquitectónico

Sitio web oficial y catálogo interactivo para Excelsior Perú.

## Estructura del Proyecto
- `index.html`: Página principal responsiva construida con Tailwind CSS, Google Fonts (Manrope), Material Symbols y JavaScript para interactividad.
  - Navegación con menú responsivo móvil.
  - Catálogo de productos en cristal templado (Puertas apilables, plegables, corredizas, duchas, batientes, pizarras).
  - Galería de proyectos con filtros interactivos.
  - Demostrador interactivo Antes / Después (slider táctil y de ratón).
  - Sección interactiva de Preguntas Frecuentes (Acordeón).
  - Formulario de cotización inmediata y enlace directo a WhatsApp.
  - Información de showroom en Miraflores y mapa de cobertura en Lima.

## Ejecución Local
Para levantar el servidor web local:
```bash
python3 -m http.server 8000
```
Y abre tu navegador en:
[http://localhost:8000](http://localhost:8000)
